# Entry notes — The Robot Pickup Line Championship

Bounty: https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b

The pickup line (91 characters, one line):

> Are you a firmware update? Because every time I see you, I want to restart and install you.

Why this line: it is a pickup line a robot would use, and the joke grows
out of being a machine — firmware, restart, install — with the turn in the
last words.

The program (`main.py`, stdlib only) writes exactly this line to
`/output/entry.txt` and asserts the gate itself: 1–200 characters, not only
white space. It is deterministic — the same bytes on every run.
